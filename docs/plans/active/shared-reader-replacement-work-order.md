整段审阅源系统栏/颜色、根运动、目标交接、加载背景、操作和返回，不能只看补丁目标。

#### Reader 原有行为基准表（验收对象，不是新开发队列）

下表是所有 Reader 包的基准；每包必须明确哪些行受影响。未受影响且证据仍适用的行沿用，不反复测试；缺少影响理由的行不能略过。当前命名运行结论与未接受分支只取顶部当前包行，不由这张基准表默认通过。

| 行为 | 预先判定的保留效果 / 失败条件 |
| --- | --- |
| 入场与返回 | 有效缩略图走根飞行；无缩略图走系统动画。禁止先全屏/改系统色再内部缩放，禁止额外缩略图等待；返回量当前目标并恢复源。 |
| 图片与加载 | 原图未准备保留当前缩略图/图像与真实反馈，进度中不丢底板；已显示请求不叠旧加载层。 |
| 翻页与预载 | 序列超过初始预载窗口继续准备，正反页序正确；快速滑动约每秒三次，不能连点冒充负载。 |
| 缩略图栏与状态 | 保留栏/Scroller/局部更新；页码不重挂整页或列表；保留已接受圆角和纯数值页码。身份检查不接受 FPS。 |
| 菜单与设置 | 原按钮/完整选项/实时语义保留；文本、勾选、底栏及实际 session 同一 canonical 值。 |
| 原图与处理结果 | ON→OFF→ON 仍可读，反馈与当前请求一致，晚回调不能覆盖新状态；系统超分沿用户暂挂。 |
| 进度与回退 | 观察页/保存页一致，原详情及普通/冷启恢复；Debug override 不证明持久默认选择。Legacy 保留。 |
| Koma/媒体能力 | 宿主章节、设置、源/本地下载和媒体动作保留；面板取消不接受实际保存/发送；未受影响命名路径不重跑。 |

每包追踪所有实际受影响行。普通入口、版本、同状态视口或依赖不适用的旧 receipt 不能代偿；
必要行缺证据保持未验收。原用户行为、源码归因和运行验收分别记录，不从候选结果推回标准。

## 进度页与时间记录

运行 `python3 scripts/serve-reader-progress.py`，打开 `http://127.0.0.1:8765`。
页面只读顶部 schemaVersion=1 JSON，无第二份队列。实际动作/结果/前置改变时更新，不只刷时间戳。
工作超过15分钟更新事实；未更新页面提示过期。每次实质源码/构建/安装/实机结果同时维护 activity、nextAction、对应宿主摘要、milestones 与已登记证据，不只更新长篇历史。当前安装包与已否决候选分别列示；拒绝候选及时撤回进度结论。页面不是任务执行器，断线或空转不得说正在推进。

`reportedAt` 只取核实原始消息时间，未知为 null；`firstEvidenceAt` 不冒充提出时间。
`handling.recordedSeconds` 仅已记录区间下界；activeSince/activeUntil 最长15分钟，失去记录停止累计，
恢复另开区间，不回填空转。历史工时、费用不完整，不能虚构完成比例或耗时。

## 本轮约束整理的边界

快照 controlCleanup 列出发现及处理，不另建长期事故/dispatch 账本。旧 Koma 主目录保留全部 WIP，
全球技能与账号 S0–S6 协议不改。原用户红线/拒绝方案保留；旧重写阶段的调度步骤不是当前路径。
本轮前置只做文档一致性、链接/归档/进度页校验；完成后恢复一次既有 E 未验收动作。
文档整理不接受 Reader 功能；该次取消分支也不接受正常完成行。不推送、不发版。
自动恢复仍每15分钟，遵守此处的最新前置，不以 429 日志作为唯一继续条件。
