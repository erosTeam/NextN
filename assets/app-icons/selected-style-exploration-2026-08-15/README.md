# NextN selected-style icon exploration

This directory preserves the complete 5 × 5 visual exploration sheet and its
25 exact cells for future icon-generation reference. The source sheet is
`nextn-reading-icon-exploration-25.png`; `tiles/r01c01.png` through
`tiles/r05c05.png` retain the row/column mapping.

## Canonical source references

Only the two files in `source-references/` are canonical single-image
generation references:

- NextN lamp: `source-references/ORIGINAL_GENERATED-nextn-lamp-exec-0d92d0d1.png`
- Koma cat: `source-references/ORIGINAL_GENERATED-koma-cat-exec-fb78f7be.png`

Their dimensions, color modes, SHA-256 hashes, and original generated-image
paths are recorded in `source-references/PROVENANCE.md`.

The exploration sheet and `tiles/` are retained as selection context only:
they are crops/derived references, not the original single-image generation
inputs. The previous redraws, audits, candidates, and 48 px exports were
removed and must not be used as source artwork.

## Generation brief

The sheet was generated as a 25-direction set for a manga/reading app, using
only the prior sheet's open-book, cat-reading, warm layered-reading, and
soft tea-cup silhouette families as references. Every new tile was requested
to retain manga/reading/story/library semantics and omit communication-app
symbols, text, labels, and brand names.
